## 🎯 What is AI Marketing Organization?

AI Marketing Organization is **NOT** a chatbot, a content writer, or a static analytics dashboard. It is an **autonomous, learning-driven marketing department** that closes the loop between business goals and verified commercial outcomes.

### The Closed Learning Loop:
```
BUSINESS GOAL (e.g. 100 patient leads / ₹50k INR)
  ↓
RESEARCH (Local search trends, competitors, pricing sensitivity)
  ↓
MARKET MODEL (Audience segmentation, localized pain points)
  ↓
STRATEGY (Positioning, channel mix, budget split in INR)
  ↓
CAMPAIGN (Flight timelines, KPIs, conversion thresholds)
  ↓
CONTENT (Multi-lingual WhatsApp, Instagram, Google Business Profile)
  ↓
DISTRIBUTION & PUBLICATION (WhatsApp Cloud, Meta Ads, Google Profile Sandbox/Live)
  ↓
MEASUREMENT (Unified event stream: impressions, clicks, qualified leads)
  ↓
ANALYSIS & ATTRIBUTION (First-Touch, Last-Touch, Linear, Assisted-Conversion)
  ↓
EXPERIMENTATION (A/B testing, statistical p-value significance)
  ↓
LEARNING (Formal organizational learnings synthesized)
  ↓
STRATEGY EVOLUTION (Strategy v1 → Strategy v2 with updated allocations)
  ↓
REPEAT
```

## 🇮🇳 India-First Architecture

Designed from the ground up for Indian SMBs (Clinics, Dentists, Real Estate, Coaching Centres, Restaurants, Salons, D2C Brands):
- **Rupee-Denominated**: Full native INR formatting (`₹`), 0% EMI payment plan reasoning (Bajaj Finserv, Pine Labs).
- **Timezone**: Indian Standard Time (`IST` / `Asia/Kolkata`).
- **Multi-Lingual Execution**: English, Hindi, Telugu, Tamil, Kannada, Malayalam, Marathi, Bengali, Gujarati, Punjabi.
- **Micro-Market Localization**: Neighborhood-level targeting (e.g. Hyderabad: *Banjara Hills, Jubilee Hills, Gachibowli, Hitec City, Kukatpally*).
- **Regulatory Compliance**: ASCI guidelines, Medical Council of India (MCI) ethical advertising screening, and RERA real estate mandates.

## 🛡️ Control Plane & Safety

Agents do not communicate in uncontrolled loops. All activity is governed by the **Control Plane**:
- **AI CEO**: Executive alignment, OKR breakdown, quarterly review.
- **Quota Manager**: Free-tier token rate limiting (RPM/TPM tracking, priority queue: `CRITICAL`, `HIGH`, `NORMAL`, `LOW`, `BACKGROUND`).
- **Deduplication Engine**: SHA-256 fingerprint caching to prevent redundant model calls.
- **Global Kill Switch**: Immediate emergency halt button pausing all autonomous executions while preserving state.
- **Approval Manager**: Risk-scored human-in-the-loop review queue (Safe, Assisted, Autonomous modes).

## 🚀 Quickstart & Local Setup

### Prerequisites
- Node.js >= 22.0.0
- npm >= 11.0.0

### 1. Clone & Install
```bash
git clone https://github.com/harshavardhankotu/ai-marketing-organization.git
cd ai-marketing-organization
npm install
```

### 2. Build Monorepo
```bash
npm run build
```

### 3. Run Automated Test Suite (19 Tests)
```bash
npm run test
```

### 4. Start Backend API Server
```bash
npm run dev:backend
# API running at http://localhost:3001
```

### 5. Start Frontend Dashboard
```bash
npm run dev:frontend
# Frontend running at http://localhost:3000
```
